## 二、当前数据结构

```csharp
/// <summary>
/// 评论规则 - 统一的规则定义
/// </summary>
public class CommentRule : INotifyPropertyChanged
{
    // === 标识 ===
    public string Id { get; set; }           // 唯一标识符
    public bool IsPredefined { get; set; }   // 是否预定义
    public bool IsActive { get; set; }       // 是否激活

    // === 匹配 ===
    public string Criteria { get; set; }     // 匹配条件（统一术语）

    // === 样式 ===
    public Foreground Foreground { get; set; }
    public Background Background { get; set; }
}
```

## 三、JSON 结构

```json
[
  {
    "Id": "9a16c17c-783b-4894-8b37-0eb7ea702905",
    "IsPredefined": false,
    "IsActive": true,
    "Criteria": "#REMOVE",
    "Foreground": {
      "IsActive": true,
      "ColorHex": "#FF808080",
      "IsBold": false,
      "IsItalic": false,
      "HasUnderline": false,
      "HasStrikethrough": true
    },
    "Background": {
      "IsActive": false,
      "ColorHex": null,
      "Shape": "Tag",
      "Blur": "None",
      "Alpha": "1/10",
      "IsCaseSensitive": true,
      "AllowPartialMatch": false
    }
  }
]
```

**说明**：

- JSON 数组的顺序就是规则的显示顺序
- 不包含 `Order` 字段
- `Foreground` 和 `Background` 对象分别存储前景和背景样式
- 便捷属性标记为 `[JsonIgnore]`，不会重复序列化

## 四、关键实现要点

### 4.1 规则优先级

当多个规则匹配同一文本时：

1. **Solution Rules** > **Global Rules**
2. JSON 数组中靠前的规则优先

### 4.2 配置变更与保存

```
规则变更（拖拽/添加/删除/修改）
         ↓
    CollectionChanged 事件
         ↓
    ┌─────────────────┐
    │ 1. 复制到 List   │  ← 避免线程安全问题
    │ 2. Task.Run 保存 │  ← 后台线程写入文件
    │ 3. 触发事件      │  ← DeferredDecorate (UI空闲时)
    └─────────────────┘
```

### 4.3 存储位置

| 类型     | 路径                                                   |
| ------ | ---------------------------------------------------- |
| 全局规则   | `%LocalAppData%\NexusHighlight\globalRules.json` |
| 解决方案规则 | `[SolutionPath]\.vs\NexusHighlight\rules.json` |
